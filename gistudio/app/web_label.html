사용법

선택·이동(V): 라벨 클릭 = 선택, 드래그 = 옮기기, 박스 모서리 드래그 = 크기 조절, 빈 곳 드래그 = 화면 이동
점(P) / 박스(B): 클릭/드래그로 새로 표시 (원본 좌표로 저장)
휠 또는 ＋－ 확대/축소 · 우클릭 드래그 어느 도구에서나 화면 이동
R·F·더블클릭 전체 보기 · Z 1:1
1 흑점 · 2 기포 · 3 선형/부메랑 파임 · 4 미세 착색 · M 마커 · N Positive↔Negative
선택한 라벨: 클래스 키로 클래스 변경 · Del 삭제 · C 확인 · 오른쪽 목록 클릭 = 그 위치로 이동
←/→ 이전/다음 프레임
Marker Ink(M)는 고객 펜 표시를 정상(Negative)으로 지정할 때 사용합니다. 점선 + 노란 태그는 AI 파일럿의 임시 라벨입니다.
